# Wildcat Recall

Wildcat Recall is an AI-powered daily study coach that recommends what to review, what assignment to work on, and how to prepare based on spaced repetition, topic mastery, and upcoming deadlines.

**Key innovation:** Instead of asking students to manually plan everything, Wildcat Recall transforms academic chaos into one clear daily action plan.

**Key learnings:** Students need tools that reduce decision fatigue, not just more dashboards. A useful academic AI should be proactive, explainable, and emotionally supportive.
